# Frontier deck rendering support

These assets serve `lecture01_part2_final_v2.qmd`.

- `theme-local.scss` is generated by `final_parts/frontier_v2_20261006/build.py`. It disables the monochrome preset's optional Google Fonts import and selects the bundled local families. The shared preset's `lecture-load-web-fonts` setting defaults to true, so other decks keep their existing behavior.
- `reveal-template-no-minimal-ui.html` is the Quarto 1.10.18 Reveal template with only the obsolete `minimal-ui` viewport flag removed. When upgrading Quarto, compare this copy with its installed template.
- `speaker-math.html` is generated from `final_parts/frontier_v2_20261006/speaker-math.template.html`. It embeds local KaTeX and font CSS and applies it to the official Reveal Notes window on its ready handshake. It does not fetch CSS or inspect cross-origin CSSOM at runtime.
- `math.html` renders author-controlled raw HTML math with strict local KaTeX.

Regenerate with the deck builder, then run Quarto. See the team validation report under `validation/frontier_team_audit_20261006/`.
