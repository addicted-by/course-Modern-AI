FLAMINGO / PERCEIVER RESAMPLER

How do many visual features become 64 tokens?

Learned latent slots repeatedly gather information from the image or video.

Input: a variable-length visual sequence

Encode each frame, add its time position and flatten the spatial and time axes.

Queries: 64 learned starting vectors

Each layer updates these slots. Their final values depend on the current image; the figure draws only five slots for clarity.

Output: 64 image-dependent vectors

Residual attention and feed-forward updates repeat across six layers.

A fixed number of queries gives a fixed number of output tokens.

Alayrac et al. · Flamingo (2022) ↗ · Figure 5, p. 23 · Appendix A.1.1

Внизу показаны кадры. Визуальный энкодер создаёт сетку признаков, к ней добавляют временные позиции. Затем признаки разворачивают в последовательность X_f. Справа находятся обучаемые латенты X, в модели их 64, хотя для ясности на рисунке нарисованы пять. Q вычисляются из текущих латентов, а K и V — из конкатенации визуальных признаков и латентов. Обозначение K=V на схеме указывает на общий источник, а не одинаковые численные значения после проекций. Attention собирает информацию, FFW преобразует каждый вектор отдельно, residual-связи прибавляют обновление. Шесть слоёв сохраняют число слотов. На выходе 64 вектора, содержание которых зависит от изображения.
FLAMINGO / GATED XATTN-DENSE

How does the language model read visual memory?

The new branch reads vision; a learned gate controls how much it changes the text states.

A gate starts at zero

y ← y + tanh(α) Δy
At initialization, the new branch leaves the pretrained text states unchanged.

Then refine each text vector

A trainable feed-forward network has its own gate. The blue language-model layers remain frozen.

The output still has one state per text token, now informed by the image.

Alayrac et al. · Flamingo (2022) ↗ · Figure 4, p. 5 · §2.2

Внизу схемы два потока: визуальные векторы X и языковые состояния Y. Cross-attention строит запросы из текста, ключи и значения из визуальных векторов. Полученное обновление умножают на tanh обучаемого скаляра alpha и прибавляют к текстовому состоянию. Alpha начинается с нуля, поэтому в самом начале новая ветка не меняет поведение готовой языковой модели. Следующий FFW независимо преобразует каждый текстовый вектор и имеет отдельный gate. Синие self-attention и FFW принадлежат замороженной LM. В оригинальной Flamingo маска cross-attention допускает для текстового токена только последнее предшествующее изображение или видео; более ранняя информация может передаваться через self-attention текста.
ATTENTION / Q, K, V

What happens inside cross-attention?

Each query chooses a weighted mixture of source values.

A = softmax(QKᵀ / √dₖ + M), O = AV

1. Match queries to keys

Q asks what to retrieve. K describes each source position. Their dot product gives a score.

2. Normalize, then mix values

Softmax normalizes each row. The weights mix V into one output vector per query.

Flamingo: gated layerText statesVisual tokens

Self-attention: Q, K, V are different projections of the same sequence.
dk: key width. M: 0 for allowed links, −∞ for blocked links.

One output vector per query. The number of keys determines where it can look.

Vaswani et al. · Attention Is All You Need (2017) ↗ · Figure 2, p. 4 · §3.2

Читайте рисунок снизу вверх. Вход Q содержит запросы обновляемой последовательности, K — ключи источника информации, V — значения этого источника. QK^T оценивает совместимость каждой пары. Деление на корень из ширины ключа стабилизирует масштаб. Маска M запрещает отдельные связи, добавляя минус бесконечность; без ограничений M равна нулю. Softmax по строке даёт веса с суммой один. Умножение на V собирает взвешенную сумму. Для text-to-vision запросы из текста, ключи и значения из изображения. В Q-Former запросы из обучаемых query-состояний. В Resampler K/V включают также текущие латенты. При self-attention источник общий, однако проекции различны, поэтому Q, K и V не обязаны совпадать. На оригинальном рисунке показана одна attention-операция; multi-head выполняет несколько таких операций с разными проекциями, объединяет результаты и линейно проецирует их.
BLIP-2 · ORIGINAL ARCHITECTURE

How do we connect two frozen models?

First learn what to extract from images; then learn how to pass it to a frozen language model.

Two stages of training

Stage 1: image–text representation learning.
Stage 2: generate text through the frozen LLM.

Train a small bridge while keeping both pretrained backbones frozen.

Li et al. · BLIP-2 (2023) ↗ · Figure 1, p. 1 · §§3.1–3.3

Figure 1 объединяет два этапа. Сначала Q-Former учится извлекать информацию по задачам сопоставления изображения и текста и генерации текста. Затем его выходы подключают к большой языковой модели через линейную проекцию и обучают через генеративную задачу. Визуальный энкодер и LLM заморожены. Queries — это внутренние обучаемые векторы. Текстовая ветка Q-Former относится к первому этапу обучения; в исходном BLIP-2 вопрос пользователя не подают в Q-Former во время обычного инференса.
BLIP-2 / Q-FORMER

What do the learned queries actually do?

32 query slots extract image information; the text branch supervises stage-1 learning.

32 learned starting vectors

Self-attention mixes query states. Output: 32 image-dependent vectors of width 768.

The query count stays fixed; training teaches the queries what visual information to retain.

Li et al. · BLIP-2 (2023) ↗ · Figure 2, p. 3 · §§3.1–3.2

Внизу слева 32 обучаемых query-вектора, каждый размерности 768. Начальные параметры общие для всех изображений, но обновления через cross-attention зависят от текущей картинки. Self-attention позволяет query-состояниям взаимодействовать. Cross-attention использует эти состояния как источник Q, а признаки замороженного энкодера как источник K и V. Он добавляется через один блок. Текстовая ветка справа показана потому, что рисунок описывает первый этап обучения. Ветки разделяют self-attention-слои, а маски определяют разрешённые связи. Вверху — три обучающие задачи, а не три последовательных операции. Последующая линейная проекция переводит 32 выходных вектора в размерность LLM.
BLIP-2 / Q-FORMER / ATTENTION MASKS

Which positions are allowed to exchange information?

Rows read from columns. White cells allow attention; gray cells block it.

Matching: all links are open

Queries and text read each other to judge image–text compatibility.

Generation: text reads the image

Text reads query slots and preceding text. Queries cannot read the caption.

Contrastive: encode separately

Encode query and text groups separately, then compare their representations.

Q = query positions, T = text positions.
These labels denote token groups.

Changing the mask changes the learning task without replacing the Transformer.

Li et al. · BLIP-2 (2023) ↗ · Figure 2, p. 3 · §3.2

Здесь Q обозначает позиции обучаемых запросов, T — позиции текста. Это не обозначения матриц Query и Key в формуле attention. Строка читает столбцы; белые ячейки разрешают связь, серые запрещают. В matching все связи открыты, так что можно оценить совместимость изображения и предложения. В генерации запросы не читают текст, зато текст читает запросы и свой доступный авторегрессионный префикс. При contrastive learning группы разделены, чтобы независимо построить представления изображения и текста и затем сравнить их. Треугольная маска на текстовых позициях сохраняет авторегрессионность: будущие токены недоступны.
BLIP-2 / VISUAL PREFIX

How do query outputs become inputs to the LLM?

A fully connected layer changes their width; the LLM consumes the resulting continuous embeddings.

32 vectors, a new width

32 × 768 → 32 × dLLM
The FC layer projects each query output into the LLM’s embedding space.

Two supported LLM layouts

OPT: prepend visual embeddings to decoder inputs.
Flan-T5: feed them to the encoder with prefix text.

What learns in stage 2?

The Q-Former and FC layer. Gradients pass through the frozen LLM to train the bridge.

A visual prefix is a sequence of vectors, not a caption converted into words.

Li et al. · BLIP-2 (2023) ↗ · Figure 3, p. 4 · §3.3

Q-Former выдаёт 32 вектора размерности 768. Fully Connected означает линейный слой, который меняет ширину каждого вектора на входную размерность LLM и сохраняет их число. Эти непрерывные представления служат визуальным префиксом, а не предварительно сгенерированной словесной подписью. В варианте OPT они поступают на вход decoder. В варианте Flan-T5 их подают в encoder вместе с текстовым префиксом, а decoder предсказывает продолжение. Заморозка LLM означает, что её параметры не обновляют, но градиенты через её вычисления доходят до Q-Former и проекции.
LLAVA · ORIGINAL 2023 MODEL

What can a simple projector unlock?

The original LLaVA uses a linear visual projector and then tunes the model on visual instructions.

Stage 1: align the features

Train W on image–text pairs. Freeze the vision encoder and language model.

Stage 2: follow instructions

Train W and the language model on image–instruction–answer examples. Keep the vision encoder frozen.

The connector supplies visual embeddings; instruction tuning teaches the assistant’s behavior.

Liu et al. · Visual Instruction Tuning (2023) ↗ · Figure 1, p. 4 · §§4.1–4.2

На оригинальной Figure 1 изображение X_v проходит через визуальный энкодер CLIP, выдающий Z_v, и линейную проекцию W. Визуальные векторы H_v поступают в LLM рядом с текстовыми представлениями инструкции H_q. Модель авторегрессионно генерирует ответ X_a. На первом этапе обновляют только W, согласуя признаки с пространством языка. На втором обновляют W и LLM на визуальных инструкциях, а визуальный энкодер остаётся замороженным. Речь об оригинальной LLaVA, где W — линейный слой, а не MLP из более поздней LLaVA-1.5.
LLAVA / LINEAR PROJECTOR

What does the projection matrix actually change?

Apply the same learned linear map to every image feature vector.

Hᵥ = WZᵥ

Input and output shapes

Zᵥ ∈ ℝ^(dᵥ × N)
W ∈ ℝ^(dLLM × dᵥ)
Hᵥ ∈ ℝ^(dLLM × N)

What stays the same?

N visual tokens. The projection changes each token’s width; it neither attends across tokens nor pools them.

N: number of image features; dv: vision width; dLLM: language-model width. Tokens are columns, as in the paper.

A projector changes the representation of each token. A resampler can also change the token count.

Liu et al. · Visual Instruction Tuning (2023) ↗ · Figure 1, p. 4 · §4.1 · Original linear projector

Увеличен оригинальный фрагмент Projection W. Если визуальные токены записаны столбцами, Z_v имеет форму d_v на N. Матрица W размера d_LLM на d_v умножается слева и даёт H_v размера d_LLM на N. Для каждого визуального токена используется одна и та же обучаемая матрица. Число N сохраняется, меняется только ширина представления. Эта операция не вычисляет веса attention и не смешивает разные позиции: взаимодействие визуальных и текстовых токенов дальше выполняет языковая модель. Здесь исходная линейная проекция LLaVA.
