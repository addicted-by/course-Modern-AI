Automatic Lyrics Transcription

Adapt speech recognition to recover lyrics from singing recordings.

What you’ll build

Fine-tune Whisper on aligned singing excerpts and compare transcription accuracy with the pretrained model.

Model and adaptation

Whisper large-v3-turbo with LoRA on q/v projections; full fine-tuning of a smaller Whisper is an optional experiment.

Whisper is the speech-recognition foundation; WhisperMSS is a reference for adapting pretrained models to Mandarin singing. General speech benchmark scores should not be treated as expected lyrics-transcription performance.

Data

Training

M4Singer Mandarin singing clips with verified Chinese text, language labels and song IDs; each aligned excerpt is at most 30 seconds.

Evaluation

Song-disjoint validation and test sets, keeping all versions of a composition in one split; add formatting labels only when available.

How to measure success

CER ↓
Character error rate, the main metric for the Mandarin course dataset.
WER ↓
Word error rate under an explicitly documented tokenization rule.
Formatting F1 ↑
Punctuation, line and section boundaries when corresponding reference labels exist.
Runtime ↓
Transcription time and memory under fixed hardware and decoding settings.

What to submit

  • A saved Whisper adapter and transcription pipeline.
  • Audio/text examples comparing the baseline and adapted model.
  • A song-disjoint CER/WER report.
  • An analysis of accompaniment, pronunciation and phrase boundaries.
