# Tools Showcase

Source: `lecture01_tools_showcase.qmd`; 34 slides, 13 tools and three groups.
The source, CSS, 10 QMD includes, navigation filter/runtime and 29 media assets
were copied from the authoring folder. Identical shared theme, template, fonts
and accessibility runtime are reused. The course header uses the same logos
as the other project lectures.

The website is generated from the authoritative `data/tools.sqlite3` catalogue.
Exact `card`, `results` and `evidence` bindings identify the source slides;
content and notes are imported on each Quarto build. No JSON registry is used.

Run `quarto render` from the repository root. See `docs/tools-catalog.md` for
maintenance. The website opens at `raw/tools-showcase.html`, the lecture at
`raw/lectures/01_intro/lecture01_tools_showcase.html` in the rendered site.
