# Local lecture fonts

The three unmodified variable TTFs are copied from the Modern AI reference presentation's `01_intro/assets/frontier_v2_20261006/fonts/` directory. Their upstream licenses are bundled with this deck. Inter and JetBrains Mono include Cyrillic. Space Grotesk uses Inter as its Cyrillic fallback.

- [Inter source](https://github.com/rsms/inter)
- [Space Grotesk source](https://github.com/floriankarsten/space-grotesk)
- [JetBrains Mono source](https://github.com/JetBrains/JetBrainsMono)
